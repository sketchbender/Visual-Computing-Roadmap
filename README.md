# Visual Computing Learning

This repository is my personal learning and experimentation repository for building a technical foundation in graphics, GPU programming, and machine learning for graphics.

---

## Tech Stack

The main technologies I'm learning are:

- **C++** — systems programming and the foundation of the stack
- **CUDA** — GPU programming and parallel computing
- **Vulkan** — low-level graphics programming
- **HLSL** — shader programming, particularly within Unreal Engine
- **Slang** — modern shader programming for graphics work
- **Unreal Engine** — real-time rendering and game development
- **PyTorch** — machine learning and GPU-accelerated ML

Alongside these, I'm building foundations in linear algebra, computer architecture, operating systems, and other areas of computer science that support the stack.

The broader direction is:

> **Graphics × GPU Programming × Machine Learning**

**Stack:** CUDA + C++ + PyTorch  
A GPU/ML project exploring a graphics-related machine-learning problem, using CUDA for the underlying GPU programming and PyTorch for the machine-learning side.

The exact project will emerge as I progress through the learning process.
