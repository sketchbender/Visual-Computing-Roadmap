# Visual Computing Learning

A personal learning and experimentation repository focused on **Graphics, GPU Programming, and Machine Learning for Graphics**.
This is an engineering journal where I document what I learn through implementations, experiments, small programs, and progressively larger projects.

## Tech Stack

- **C++**
- **CUDA C++**
- **Vulkan**
- **HLSL**
- **Slang**
- **Unreal Engine**
- **PyTorch**
- **Python**

These tools are supported by foundations in:

- Linear Algebra
- Computer Architecture
- Operating Systems
- Data Structures & Algorithms
- Computer Graphics
- GPU Programming
- Machine Learning
