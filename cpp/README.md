# C++

Systems programming foundation for the entire visual computing stack.

---

## Focus Areas

- **Modern C++ (17/20)** — move semantics, smart pointers, RAII, constexpr, structured bindings
- **STL & Data Structures** — containers, algorithms, iterators
- **Memory Model** — stack vs heap, alignment, cache-friendly layouts
- **Templates & Metaprogramming** — variadic templates, SFINAE, concepts (C++20)
- **Multithreading** — std::thread, mutexes, atomics, condition variables, lock-free patterns
- **Build Systems** — CMake, compiler flags, linking

---
